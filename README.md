# 業績管理アプリ

論文・学会発表・講義などの業績を登録し、**業績目録**として出力する Web アプリです。

- ビルド不要の静的サイト（HTML + CSS + バニラ JavaScript、外部依存ゼロ）
- データはブラウザ内（localStorage）に保存され、外部に送信されません（DOI 取得時の CrossRef への問い合わせを除く）
- 共著者・所属・ジャーナル名と略称を記憶し、次回以降は候補から選べます
- **所属を階層構造（機関 ＞ 学部・研究科 ＞ 学科・専攻 ／ 研究所 ＞ 部門 ＞ グループ）で登録**できます
- 著者・所属に英名を紐づけ、英文誌や国際学会では英名で出力できます
- JSON バックアップにより、アプリを更新しても入力内容を引き継げます
- カラーテーマ: `#b5b5ac`

## 画面構成

| タブ | 内容 |
|---|---|
| 業績の入力 | 区分と表記言語に応じた入力フォーム。DOI からの自動入力、入力中のプレビュー |
| 業績一覧 | 検索（和文・英文・上位の所属も対象）・並べ替え・編集・複製・削除 |
| 業績リスト出力 | 所属の階層の表し方の設定、HTML / Markdown / テキスト / CSV / BibTeX / RIS / 科研費様式 / 印刷 |
| 年度別集計 | 年度（4月〜翌3月）または暦年での件数推移と区分別内訳 |
| マスタ管理 | 所属（階層・和英）・共著者・ジャーナル・大会名の登録・編集・削除 |
| データ入出力 | JSON バックアップの保存と読み込み、登録状況の確認 |

## 所属の階層

各所属に**上位の所属**を設定することで、何段でも（最大 8 段）階層を作れます。

```
東京大学（東京大 / The University of Tokyo, UTokyo）
  └ 大学院理学系研究科（院理 / Graduate School of Science）
      └ 生物科学専攻（Department of Biological Sciences）
産業技術総合研究所（産総研 / AIST）
  └ 地質調査総合センター（GSJ / Geological Survey of Japan）
```

各段に名称・略称・英語名称・英語略称を登録できます。

### 業績の入力画面での登録と選択

著者行の「新しい所属」に **上位の所属** の選択欄があります。

1. 上位なしで「東京大学」を登録する
2. 上位に「東京大学」を選んで「大学院理学系研究科」を登録する
3. 上位に「大学院理学系研究科」を選んで「生物科学専攻」を登録する

同じ系統の上位の所属をすでに選んでいる場合、より下位の所属を登録・選択すると**下位に置き換わります**
（「東京大学」を選んだ著者に「生物科学専攻」を追加すると、「東京大学 ＞ 大学院理学系研究科 ＞ 生物科学専攻」の 1 件になります）。

「過去の所属から選択」の選択肢は、親の直後に子が字下げされて並びます。著者には**最も下の階層**を選ぶと、
上位の機関名も含めて出力されます。選んだ所属は「東京大学 ＞ 大学院理学系研究科 ＞ 生物科学専攻」のように階層つきで表示されます。

### マスタ管理での編集

- 一覧は階層順に字下げして表示し、下位の件数も表示します
- 各行の **「下位を追加」** で、その所属の下に学部・専攻・部門などを続けて追加できます（追加後も上位の選択は残ります）
- 「編集」で上位の所属を変更すると、**下位の所属もまとめて移動**します
- 自分自身や自分の下位を上位にすることはできません（選択肢にも出ません）
- 下位の所属がある所属、業績や共著者の既定の所属として使っている所属は削除できません
- 同じ上位の中で同じ名称は登録できませんが、**別の大学の「理学部」などは別の所属**として登録できます

### 出力での表し方

「業績リスト出力」タブの **所属の階層** で、出力に使う階層を選べます（設定は保存され、入力画面のプレビューにも反映されます）。

| 設定 | 日本語表記 | 英語表記 |
|---|---|---|
| すべての階層（既定） | 東京大 院理 生物科学専攻 | Department of Biological Sciences, Graduate School of Science, UTokyo |
| 最上位（機関名）のみ | 東京大 | UTokyo |
| 登録した階層のみ（最下位） | 生物科学専攻 | Department of Biological Sciences |

- 日本語は**上位から下位**の順に半角スペースで、英語は**下位から上位**の順にカンマで連結します
- 各段は略称があれば略称を使います（英語は英語略称 → 英語名称 → 和文の順）
- 英語表記で階層つきの所属が複数ある場合は、所属の区切りを「; 」にして読み違いを防ぎます

```
儀武滉大（東京大 院理 生物科学専攻・産総研 地質調査総合センター）・井口亮（産総研 地質調査総合センター）.「…」.

Gibu, K. (Department of Biological Sciences, Graduate School of Science, UTokyo; GSJ, AIST), Iguchi, A. (GSJ, AIST). "…".
```

CSV の所属列は、設定にかかわらず**すべての階層の正式名称**を出力します。

## 著者・所属の英名と表記言語

- 共著者に英語表記（Gibu, K.）、所属に英語名称・英語略称を登録できます
- 業績ごとに表記言語（自動判定 / 日本語 / 英語）を選べます。自動判定では国際学会と、タイトル・掲載誌名に日本語を含まない論文が英語表記になります
- 英語表記では英名を使い、未登録の著者・所属は和文で出力し、入力画面に警告を表示します
- 自分の氏名は和文・英文どちらでも太字＋下線になります

## DOI から書誌情報を自動取得（CrossRef）

DOI を入力すると CrossRef REST API から書誌情報を取得します。英語の著者名は登録済みの共著者に
（「Gibu, Kodai」「Gibu, K.」「Kodai Gibu」を同一人物とみなす）、英語の所属名は**下位の階層も含めて**登録済みの所属に紐づけます。

## その他の機能

- 業績区分: 論文（査読有 / 無）、学会発表（国内 / 国際 × 口頭 / ポスター）、シンポジウム、講義、競争的資金、受賞、その他
- BibTeX / RIS（Zotero・EndNote 向け）、科研費様式、年度別集計

## アプリ更新時のデータ引き継ぎ

1. 更新前に「データ入出力」→「**JSONファイルに保存**」
2. アプリを更新（再デプロイ）
3. 「**JSONファイルを読み込む**」で復元（既存データへの追加 / すべて置き換え）

データのスキーマ版数は **v4** です。以前のバージョンのバックアップを読み込むと、既存の所属はすべて最上位の所属になります
（あとからマスタ管理で上位を設定できます）。存在しない上位や循環した上位を指すデータは自動で最上位に戻します。
「既存データに追加」では、所属を上位から順に取り込み、**同じ上位 × 同じ名称**の所属を 1 つにまとめます。

## 検証済み項目（`npm test` / 全33件）

**所属の階層（今回追加）**

- 上位を指定した登録と階層パス・深さ、別の上位にある同名所属の区別
- 存在しない上位・最大段数の超過のエラー
- 階層順の一覧（親の直後に子・同じ階層は名称順）
- 下位の一覧、自分自身・自分の下位を上位にできないこと、下位がある所属の削除防止
- 出力の階層の表し方（すべて / 最上位 / 最下位、和文は上→下、英文は下→上）と設定の反映
- 英語表記で階層つきの複数所属を「; 」で区切ること、英名未登録の段の和文補完
- 同じ上位の中での英語名称による同一判定、全階層からの英語名検索
- CSV は常にすべての階層、v3 以前のデータと不正な上位の移行
- マージ読み込みでの階層の保持と統合、置き換え読み込みでの設定の保持、機関数の集計

**既存機能**

- 所属・共著者の和英、表記言語、英文誌の出力、日付の和英表記、CSV の和英列
- マスタの重複防止・使用件数、旧形式の所属文字列の移行、業績リスト・JSON 入出力
- DOI と CrossRef（下位の所属への紐づけを含む）、BibTeX / RIS / 科研費様式、年度別集計
