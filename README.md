# 業績管理アプリ

論文・学会発表・講義などの業績を登録し、**業績目録**として出力する Web アプリです。

- ビルド不要の静的サイト（HTML + CSS + バニラ JavaScript、外部依存ゼロ）
- データはブラウザ内（localStorage）に保存され、外部に送信されません（DOI 取得時の CrossRef への問い合わせを除く）
- 共著者・**所属（名称＋略称）**・ジャーナル名とその略称を記憶し、次回以降は候補から選べます
- JSON バックアップにより、アプリを更新しても入力内容を引き継げます
- カラーテーマ: `#b5b5ac`

## 画面構成

| タブ | 内容 |
|---|---|
| 業績の入力 | 区分に応じて入力項目が切り替わるフォーム。DOI からの自動入力、入力中のプレビュー |
| 業績一覧 | 登録済み業績の検索・並べ替え・編集・複製・削除 |
| 業績リスト出力 | HTML / Markdown / テキスト / CSV / BibTeX / RIS / 科研費様式 / 印刷 |
| 年度別集計 | 年度（4月〜翌3月）または暦年での件数推移と区分別内訳 |
| マスタ管理 | 所属・共著者・ジャーナル・大会名の登録・編集・削除 |
| データ入出力 | JSON バックアップの保存と読み込み、登録状況の確認 |

## 業績区分と入力項目

| 区分 | 入力項目 |
|---|---|
| 論文（査読有 / 査読無） | 共著者と所属、論文タイトル、ジャーナル名・略称、発表年月日、巻（創刊号）・号、ページ番号 / 文献番号、査読の有無、DOI |
| 学会発表（国内 / 国際 × 口頭 / ポスター） | 共著者と所属、発表タイトル、大会名、発表日、発表番号、会場 |
| その他（シンポジウム・講義・実習・受賞・競争的資金など） | 共著者と所属、件名、名称、日付、会場、備考 |

## 共著者と所属の入力

所属は**著者ごとに 1 件ずつ**、名称と略称の組で登録します。各著者の行は次の 3 段構成です。

```
[1] 氏名: 儀武滉大  (自分)                              ↑ ↓ ×
    所属: [東京大学 東京大 ×] [◀ 産業技術総合研究所 産総研 ×]
    過去の所属から選択: [（所属を選ぶ）      ▼] [追加]
    新しい所属: [名称_____________] [略称_____] [登録して追加]
```

### 過去の所属から選択

これまでに登録した所属が「名称（略称）」の形でプルダウンに並びます。選ぶだけで追加され、
その著者に選択済みの所属は候補から除かれます。

### 新しい所属を登録

名称と略称を入力して「登録して追加」を押すと（Enter キーでも可）、所属マスタに記憶され、
次回からは「過去の所属から選択」に表示されます。

- 同じ名称の所属は重複登録されません。登録済みの名称を入力すると、その略称が自動で入ります
- 登録済みの所属に略称が無ければ、入力した略称で補完されます
- 登録済みの略称と**異なる略称**を入力した場合は、変更するかどうか確認します
  （変更するとその所属を使うすべての業績の出力に反映されるため、意図しない書き換えを防ぎます）

### その他の動作

- 複数の所属は追加した順に出力されます。チップの「◀」で順序を入れ替え、「×」で外せます
- 一度入力した氏名を選ぶと、**その人の既定の所属が自動で入ります**（所属が未設定の場合のみ）
- 「自分を先頭に追加」は、自分の既定の所属もあわせて入れます
- 業績リストでは**略称が優先**されます（略称が無い所属は正式名称）。CSV 出力では正式名称を使います

```
儀武滉大（東京大・産総研）・井口亮（産総研）.「南西諸島における造礁サンゴの細菌叢解析」. ...
```

### マスタ管理での所属の編集

「マスタ管理」タブの「所属」で、名称・略称の追加と編集ができます。
所属は ID で参照しているため、**名称や略称を変更すると、その所属を使っているすべての業績の出力に反映されます**
（例: 「産業技術総合研究所」→「国立研究開発法人 産業技術総合研究所」）。
業績や共著者の既定の所属として使われている所属は、誤削除を防ぐため削除できません（使用件数を表示します）。

共著者の**既定の所属は複数設定**できます（Ctrl / ⌘ キーを押しながら選択）。

## DOI から書誌情報を自動取得（CrossRef）

論文区分で DOI を入力して「取得して入力欄に反映」を押すと、CrossRef REST API から書誌情報を取得し、
タイトル・ジャーナル名・略称・発行年月日・巻・号・ページ・DOI・著者を入力欄へ反映します。
CrossRef に登録された著者の所属は所属マスタへ記憶されます（略称は後から追加できます）。

```
10.1038/s41598-024-74596-x
https://doi.org/10.1038/s41598-024-74596-x
doi:10.1038/s41598-024-74596-x
```

## 自分の氏名の強調

「マスタ管理」の**自分の氏名表記**に登録した名前は、出力時に**太字＋下線**になります。
和文名・英文名・別表記を改行区切りで複数登録でき、空白の有無は無視して判定します。

## 出力形式

| 形式 | 用途 |
|---|---|
| HTML | Word に貼り付けると太字・下線・斜体がそのまま反映されます |
| Markdown | 文書管理システム向け |
| テキスト | プレーンテキストが必要な申請書類向け |
| CSV | Excel で集計・並べ替え（UTF-8 BOM 付き） |
| BibTeX | Zotero・EndNote・LaTeX 向け（ASCII 引用キー） |
| RIS | Zotero・EndNote・Mendeley 向け（ページ範囲は SP / EP に分割） |
| 科研費様式 | 〔雑誌論文〕〔学会発表〕〔その他〕の研究発表欄の体裁 |
| 印刷 / PDF | ブラウザの印刷機能で PDF として保存 |

「プレビューをコピー」は書式付きでクリップボードに入るため、Word へ直接貼り付けられます。

## 年度別集計

- 年度（4月〜翌3月）と暦年を切り替え可能（例: 2025年3月の発表は **2024年度**）
- 月が未入力の業績はその年の年度、年が未入力の業績は集計対象外として件数を表示
- 年度ごとの棒グラフ、区分別クロス集計表、合計行、CSV 出力

## アプリ更新時のデータ引き継ぎ

1. 更新前に「データ入出力」→「**JSONファイルに保存**」
2. アプリを更新（再デプロイ）
3. 「**JSONファイルを読み込む**」で復元

| 読み込み方法 | 用途 |
|---|---|
| 既存データに追加（重複は除外） | 別の端末で入力した分を統合。所属・共著者などのマスタは名称でまとめられます |
| すべて置き換える | バックアップから完全に復元 |

データにはスキーマ版数（現在 v2）を持たせています。以前のバージョンで保存した
「A・B」形式の所属文字列は、読み込み時に自動で所属マスタへ登録され、ID 参照に変換されます。

## ローカルでの確認

ES Modules を使うため、`file://` で直接開かずローカルサーバー経由で開いてください。

```bash
npm run dev            # npx serve .  → http://localhost:3000
# または
python -m http.server 8000
```

テスト（Node.js 18 以上）:

```bash
npm test
```

## GitHub → Vercel へのデプロイ

```bash
cd achievement-manager
git init
git add .
git commit -m "feat: 所属の個別登録・略称・過去の所属の選択に対応"
git branch -M main
git remote add origin https://github.com/<ユーザー名>/achievement-manager.git
git push -u origin main
```

1. [vercel.com](https://vercel.com) にログイン → **Add New… → Project**
2. 対象リポジトリを **Import**
3. Framework Preset は **Other**（`vercel.json` によりビルドは実行されません）
4. Root Directory はリポジトリ直下のまま → **Deploy**
