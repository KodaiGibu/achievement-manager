# 業績管理アプリ

論文・学会発表・講義などの業績を登録し、**業績目録**として出力する Web アプリです。

- ビルド不要の静的サイト（HTML + CSS + バニラ JavaScript、外部依存ゼロ）
- データはブラウザ内（localStorage）に保存され、外部に送信されません（DOI 取得時の CrossRef への問い合わせを除く）
- 共著者・所属・ジャーナル名と略称を記憶し、次回以降は候補から選べます
- **著者・所属に英名を紐づけ**、英文誌や国際学会では英名で出力できます
- JSON バックアップにより、アプリを更新しても入力内容を引き継げます
- カラーテーマ: `#b5b5ac`

## 画面構成

| タブ | 内容 |
|---|---|
| 業績の入力 | 区分と表記言語に応じた入力フォーム。DOI からの自動入力、入力中のプレビュー |
| 業績一覧 | 検索（和文・英文）・並べ替え・編集・複製・削除 |
| 業績リスト出力 | HTML / Markdown / テキスト / CSV / BibTeX / RIS / 科研費様式 / 印刷 |
| 年度別集計 | 年度（4月〜翌3月）または暦年での件数推移と区分別内訳 |
| マスタ管理 | 所属・共著者（和英）・ジャーナル・大会名の登録・編集・削除 |
| データ入出力 | JSON バックアップの保存と読み込み、登録状況の確認 |

## 著者・所属の英名

### 登録できる項目

| マスタ | 和文 | 英文 |
|---|---|---|
| 共著者 | 氏名（儀武滉大） | 英語表記（Gibu, K.） |
| 所属 | 名称（産業技術総合研究所）・略称（産総研） | 英語名称（National Institute of Advanced Industrial Science and Technology）・英語略称（AIST） |

業績入力の著者行で、氏名と並べて**英語表記**を入力できます。所属は「新しい所属」に
名称・略称・**英語名称・英語略称**の4項目を入力して登録します（英語の入力欄は淡い青色）。
登録した内容は記憶され、次回からは選ぶだけで和英の両方が入ります。

- 氏名欄は和文名・英語表記のどちらで入力・選択しても、同じ共著者に紐づきます
  （「Gibu, K.」を選ぶと氏名「儀武滉大」と既定の所属が自動で入ります）
- 新しい所属の名称欄または英語名称欄に登録済みの名前を入れると、残りの項目が自動で補われます
- 所属チップには和文名・略称とあわせて英語略称（未登録なら「英名未登録」）が表示されます
- 「過去の所属から選択」の選択肢は「名称（略称） / English Name (Abbr)」の形で表示されます
- 登録済みの値と異なる略称・英語名称・英語略称を入力した場合は、項目ごとの差分を示して更新するか確認します
- 「マスタ管理」タブで後から英名を追加・修正できます。英名の登録件数も表示されます

### 表記言語

業績ごとに **表記言語**（自動判定 / 日本語表記 / 英語表記）を選べます。入力欄の横に、
実際にどちらで出力されるかが「→ 英語表記で出力（自動）」のように表示されます。

| 自動判定のルール | 出力 |
|---|---|
| 国際学会（口頭・ポスター）の区分 | 英語 |
| タイトル・掲載誌名（大会名）に日本語を含まない | 英語 |
| それ以外 | 日本語 |

英語表記では、著者名は**英語表記**、所属は**英語略称 → 英語名称**の順で使い、区切りや日付も英語の形式になります。
英名が未登録の著者・所属は和文で出力され、入力画面に「英語表記が未入力の著者」「英語名称が未登録の所属」の警告が表示されます。

```
国際学会（英語表記）:
Gibu, K. (UTokyo, AIST), Iguchi, A. (AIST). "Microbiome Analysis of Reef-Building Corals".
1st Asia-Pacific Biodiversity Joint Conference. 23 October 2024. No. 23-VI-4.

英文誌（英語表記）:
Gibu, K., Iguchi, A. (2024). Polyamine impact on physiology of early stages of reef-building corals.
Scientific Reports, 14(1), 23465.

国内学会（日本語表記）:
儀武滉大（東京大・産総研）・井口亮（産総研）.「南西諸島における造礁サンゴの細菌叢解析」.
日本生態学会第72回全国大会. 2025年3月15日. 発表番号I01-01.
```

自分の氏名は和文・英文どちらの表記でも**太字＋下線**になります（「マスタ管理」の自分の氏名表記に両方を登録してください）。

### 各出力形式での扱い

| 出力 | 英名の扱い |
|---|---|
| 業績リスト（HTML / Markdown / テキスト） | 業績ごとの表記言語に従う |
| CSV | 和文・英文の著者と所属を別の列に出力し、表記言語の列も追加 |
| BibTeX / RIS | 著者は表記言語に従う。BibTeX の引用キーは英語表記の姓から作成（ASCII） |
| 科研費様式 | 表記言語に従い、英語表記の業績は著者を「, 」区切り・日付を英語形式で出力 |

## DOI から書誌情報を自動取得（CrossRef）

論文区分で DOI を入力して「取得して入力欄に反映」を押すと、CrossRef REST API から書誌情報を取得します。
CrossRef の著者名（英語）は、**英語表記が一致する登録済みの共著者に自動で紐づけ**ます。
「Gibu, Kodai」「Gibu, K.」「Kodai Gibu」は姓と名の頭文字で照合し、同一人物とみなします。
著者の所属（英語）も、英語名称・英語略称が一致する登録済みの所属に紐づけ、未登録なら英語名称として記憶します。

## その他の機能

- **業績区分**: 論文（査読有 / 無）、学会発表（国内 / 国際 × 口頭 / ポスター）、シンポジウム、講義、競争的資金、受賞、その他
- **所属**: 過去の所属から選択、または新しい所属を登録。複数所属の並べ替え、共著者ごとの既定の所属
- **科研費様式**: 〔雑誌論文〕〔学会発表〕〔その他〕に振り分け、査読・国際学会・招待講演を判定
- **年度別集計**: 年度と暦年の切り替え、棒グラフ、区分別クロス集計、CSV 出力

## アプリ更新時のデータ引き継ぎ

1. 更新前に「データ入出力」→「**JSONファイルに保存**」
2. アプリを更新（再デプロイ）
3. 「**JSONファイルを読み込む**」で復元（既存データへの追加 / すべて置き換え）

データにはスキーマ版数（現在 **v3**）を持たせています。以前のバージョンのバックアップを読み込むと、
所属の英語名称・英語略称と業績の表記言語（自動判定）が自動で補われます。
v1 の「A・B」形式の所属文字列も所属マスタへ移行されます。

## ローカルでの確認

```bash
npm run dev            # npx serve .  → http://localhost:3000
# または
python -m http.server 8000
```

テスト（Node.js 18 以上）:

```bash
npm test
```

## GitHub → Vercel へのデプロイ

```bash
git add .
git commit -m "feat: 著者・所属の英名と表記言語に対応"
git push
```

Vercel の Framework Preset は **Other**（`vercel.json` によりビルドは実行されません）。
